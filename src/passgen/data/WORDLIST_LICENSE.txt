The bundled english.txt contains all 7,776 source words in their original
order. The numeric dice-roll column has been removed. At runtime passgen
removes hyphens and deduplicates the normalized words before uniform
selection. These modifications are by passgen contributors. No EFF
endorsement is implied. This data is separate from passgen's MIT code license.
